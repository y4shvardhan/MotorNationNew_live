# MotorNation

MotorNation is an automotive research and comparison platform focused on
new vehicles available in the United States.

The project provides:

- Vehicle search
- Vehicle filtering
- Vehicle details
- Vehicle comparison
- Automotive reviews
- Automotive news
- EV information
- Vehicle specifications
- Automotive data collection and processing
